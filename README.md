# 🏦 Sistema Bancário

Um sistema bancário simples e eficiente, desenvolvido para simular operações financeiras do dia a dia. Todas as transações, dados de usuários e métricas são persistidos e consultados diretamente em um **banco de dados**, garantindo integridade e atualização em tempo real.

---

## ✨ Funcionalidades

O sistema conta com as seguintes operações principais:

* **📝 Criar Conta:** Cadastro de novos clientes no sistema, gerando um número de conta e inicializando o saldo.
* **💵 Depósito:** Adição de valores à conta do usuário. O saldo é atualizado imediatamente no banco de dados.
* **🏧 Saque:** Retirada de valores da conta. O sistema realiza a validação de saldo disponível antes de autorizar a transação.
* **📊 Tabela de Estatísticas:** Um painel detalhado gerado a partir do banco de dados que exibe métricas importantes, como total de movimentações, histórico de transações, contas ativas e volume financeiro operado.
